# Сайт для QR-кода на торте

## Как работает

QR-код должен вести на страницу `index.html`.

Пока видео нет, посетитель увидит красивую заглушку.

После съёмки:

1. Назови видео `video.mp4`.
2. Положи `video.mp4` рядом с `index.html`.
3. Залей обновлённые файлы на тот же хостинг.
4. QR-код менять НЕ нужно.

## Важно

Этот вариант рассчитан на статический хостинг. Сам сайт не загружает видео через браузер — видео добавляется на хостинг вместе с файлами.

Если нужен вариант, где можно зайти в `/admin`, выбрать видео и загрузить его без ручного обновления файлов, можно сделать следующую версию с хранилищем и админкой.
